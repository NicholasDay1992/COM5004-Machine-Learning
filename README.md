# COM5004-Machine-Learning
This is a template of the COM5004 Machine Learning module. Students are required to have taken the COM4008 Programming Concepts module so they have a foundation in Python.

It contains lecture slides, links to lecture recordings and resources, in addition to code and project files to get started. Make sure that you 'use this template' or at least 'fork' this repository, to ensure that you can commit any local changes that you make.

This module starts with Exploratory Data Analysis and Data Visualisation, before going on to look at the Supervised, Unsupervised and Reinforcement Learning Paradigms of Machine Learning.
